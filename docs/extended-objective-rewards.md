# Structural destruction and Escort delivery XP

The source-owned Acquisition and Domination callbacks settle eight authored Structural destruction rewards. Acquisition also settles one Escort Vehicle Delivered reward for the current operator. The existing immutable progression transaction continues to own XP, shared fractional carry, optional FRAGO/stat3, levels and receipts.

## Structural callback and actor rules

Structural Completed entered from Activated or Deactivating selects the destruction award from its authored subtype. Subtypes3/4/5/7/8/11/13/14 map to stats42/44/46/48/50/52/54/56. Amounts come from the selected progression catalog. A supported subtype also contributes one zero-XP ChargesDetonated61 counter; Gameplay commits that companion with the destruction counter on the once-only ACK path. No extra Horizon receipt, XP or carry operation represents stat61. Completion during defuse earns the subtype award but no primary-secured increment. When eligible, subtype credit precedes the existing primary-secured reward. Unsupported subtypes, repair, canceled holds and non-armed entries do not acquire these destruction awards.

Qualified callback attribution is independent of the replicated wire actor. A Precision request resolves the cached source slot in its original world against the current allocated character and team. An attacker-side source updates the attacker latch; an owner-side source updates the defender and preserves the planter; an unresolved source preserves both. Dead or respawned current characters are not rejected by an old life-generation test. An Inactive cascade passes through Deactivated and clears its attacker. Intermediate Activated under desired Completed emits no planting callback. Final Completed from the armed states uses the resulting attacker latch. These rules also cover the source-classified passive Acquisition Precision path.

A destroyed trigger directly installs its resolved source as attacker, including owner-side damage, following the separately qualified native trigger admission. Its timer and completion retain that actor independently of wire publication. The existing gameplay admission, damage and blast source behavior are preserved. Generic scripted actor attribution remains unqualified unless represented by a proved callback path.

## Acquisition delivery timing

The retail vehicle-contact path reports one local operator, rather than one reward per passenger. The replacement retains its authoritative operator, source vehicle, trigger, clearance and match checks. The native Arrival transition awards stat59 synchronously before its script/assignment refresh and before dismounting occupants. The replacement captures the mounted operator pose after all exits have been planned and binds it to that exact pending Completion request. It evaluates FRAGO only when that request actually enters Completed, using the saved pose and actual Arrival context with the callback's current assignment and target poses. A canceled or superseded request earns no reward, even if a later request restores the same target. A failed record, exit installation or later callback installs neither XP nor partial delivery authority.

The current replacement’s broader ejection/controller-effect ordering is unchanged. Freezing reward context at the native time does not claim a new live qualification of those other effects. A completed Arrival rejects repeat delivery, and each receipt retains round, objective, event time and admission identity. Passengers receive no delivery reward.

## Bridge and durable compatibility

Hello advertises `extended_objective_rewards_v1`. Horizon emits optional `extended_objective_rewards_enabled` only for a negotiating peer and enables it for retail only when all nine authored amounts are valid. The added aliases are `defensive_emplacements_destroyed`, `bridges_destroyed`, `fortifications_destroyed`, `gates_destroyed`, `mortars_destroyed`, `sensor_networks_destroyed`, `anti_aircraft_destroyed`, `motor_pools_destroyed` and `escort_vehicle_delivered`. Each requires one unit. A partial well-formed group disables these new kinds without disabling the existing six objective awards; malformed authored values follow catalog validation failure.

New gameplay omits the aliases when the additional admission is absent or false. New Horizon omits the additional field for older gameplay. Contextual bonuses additionally require the independently negotiated objective FRAGO admission. Base-only rewards remain valid with no bonus coefficient. Original reservations retain permission for queued rewards after release.

No saved fields or schema version are added. Updated readers recognize the additional immutable aliases; older binaries reject a store containing them. Preserve receipt histories when rolling back. Exact saved replay precedes current per-kind rule checks, while new receipts require current valid amounts. Destruction/stat61 ACKs share record-before-install, same-round/detached-participation handling and duplicate protection. Prior-round ACKs can advance account progression without altering current-round counters.

## Qualification boundary

Retail code and authored rules were verified privately; public fixtures are synthetic. New map-data formats are unnecessary: the existing reward classifier already carries subtype, and the progression extractor already preserves these authored amounts. All original archives, populated catalogs and raw evidence remain private. Source tests, offline startup and profile selection do not establish native live-match acceptance. Releases remain manual after human review.
