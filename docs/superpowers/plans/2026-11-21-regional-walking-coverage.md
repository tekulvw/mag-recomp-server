# Regional Walking Coverage Implementation Plan

**Goal** Admit one source-qualified bounded runtime walking mesh while preserving the original collision world and other query authorities.

**Architecture** A neutral producer checks full fixed geometry and linked source evidence. A strict walking capability binds that geometry, world, and box. Dedicated preparation, bake, and runtime loaders carry the capability hash. Only the existing regional collision guard can transfer this authority to physical walking.

- [ ] Add synthetic negative and positive projection/format tests before implementation. Validate source-world equality, exact qualification links, bounds and hostile input.
- [ ] Add scoped runtime prep/bake/load using unchanged default Recast profile. Ordinary and reference formats reject the scoped input. Refuse drops.
- [ ] Bind exact world and box in RegionalCollision and pass authority only into guarded WorldTerrain. Verify every support/sweep envelope and preserve generic drop certification.
- [ ] Validate retained original Alaska evidence, bake independently, and verify ordinary scoped artifact reopen and path queries. Keep source files immutable; actual population run depends on the independently merged source team allocation feature.

## Operator inputs

Project with tools/navmesh/project-regional-walk-coverage.py and privately retained source files. The projector compares ordered geometry, checks the fixed root census and linked omissions, opens the original map CLV, checks the original Main and ELF hashes and verifies the retained absence spans. The operator approves that external qualification and pins the resulting raw capability hash. Digest fields alone provide no proof of native semantics.

Pass the resulting file to tools/navmesh/prepare.py with --regional-walk-coverage and the exact world hash. Run mag-navmesh bake-regional-walk with --input, --coverage and --output, and use query-regional-walk with that artifact, exact --collision-world and --coverage plus start, goal, and goal radius. The regional artifact uses the existing default numerical bake.

For a direct retail worker, pass the scoped artifact as --navmesh-world and the sidecar as --regional-walk-coverage. The fixed bot population's regional_collision object pins walking_coverage_sha256 and walking_detour_sha256 together alongside its existing source identities and the exact box. The worker's catalog-only check verifies those bindings. Full bot startup also uses the existing live guard and spawn admission. The raw collision world retains the original metadata. Standard and reference navigation, legacy fall/drop certification, material tracing, and projectile queries use their usual input contracts.
