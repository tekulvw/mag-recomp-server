# Acquisition authoritative effect qualification

The human authorized the authoritative Acquisition effect backend, remaining
native qualification and checked source integration, with manual releases after
live-match review. Extend the current engine using rg/direct reads; no XERJ.
Source/offline work does not resume game runs or deployments.

## Approach

Qualify native effect boundaries before installing them. Reuse original-byte
PPC/DWARF bridges and keep their receipts private. Implement the fully bounded
behavior in small Rust modules with critical synthetic regressions. A complete
callback backend must own and stage the actual objective, FSP/vehicle, character,
mine, assignment and publication state; an invented effect world or a collection
of empty handlers cannot qualify it. Native initial-load objective evidence stays
pre-MissionStart. Missing native body coverage or lifecycle effects must remain
explicit errors rather than guessed physics or terminal damage.

## Native questions

- Complete temporary-volume transform/filter/query and current collidable body
  mapping, preserving ordered penetration pairs and multiplicity.
- Complete character/ground lethal damage and later mine explosion consequences.
- Native previous-state entry bookkeeping, immediate FSP spawn/vehicle behavior,
  and the post-Lua global assignment sweep with primary/FRAGO selection.

## Proven component targets

Native objective commands request target states without changing current state.
Enable guards current0, Disable current!=0, Lock current!=9; identical pending
requests are no-ops. Assignment order validity uses owner-team equality and raw
current state, with ordered Take/Hold lists and independent primary/tag results.
Implement only supported branch behavior backed by complete bridges, including
native early returns and manual tag preservation. Extend volume/lethal helpers
only when exact metadata and arithmetic have been bound.

## Completion boundary

Integrate source components after affected checks and public CI pass. Record
qualified and unresolved behavior separately in the private TODO/evidence.
Install a concrete callback backend only when all required effects and complete
current collision queries are qualified. Never describe partial primitives as
live controller gameplay. Preserve released submodule pin, accounts and unrelated
indices/evidence; no tags, release merges or publication.
