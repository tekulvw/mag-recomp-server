# Extract retail infantry rocket rules

The owner-run projector derives one launcher row for each faction's original starter Heavy kit. It reads the owned retail executable and game archive, joins gear slot 3 and its equipped sight to the attested global item list, and verifies the selected definitions against the archived data. The original gear byte, projectile-family allocation, contact capsule, arming timer, range terminal and blast origin are checked against the retail executable.

Use the same retail item catalog, item-binding report and all-faction bootstrap loadouts accepted by the existing retail combat projector. Run from this checkout with explicit input paths.

```sh
python3 tools/extraction/project-retail-infantry-rockets.py \
  --elf /owned/original/mage_g.elf \
  --game-archive /owned/original/game.psarc \
  --item-catalog /private/retail-items.json \
  --item-bindings /private/retail-item-bindings.json \
  --bootstrap-loadouts /private/retail-all-factions-bootstrap-loadouts.json \
  --output /private/infantry-rockets.json \
  --proof-output /private/infantry-rockets-proof.json
```

Create output files at unused paths outside this checkout. Omit `--proof-output` when only the catalog is needed. Add `--check` to compare regenerated bytes with all requested outputs without writing them. Unsupported executable, archive or equipment bindings fail validation.

The `mag_retail_infantry_rockets_v1` catalog keeps the finite initial magazine count and authored weapon cadence separate from flight and blast data. The capsule's local spine is the full authored vector. Its endpoints are half that vector in opposite directions around the projectile root. Flight also carries the authored impact arming time, displacement cutoff, lifetime and the separately verified original age allowance. The damage rows give distinct Character and vehicle inputs for the shared Debris explosion. It centers on the projectile root at the terminal pose. The optional proof records source-member digests, selected item provenance, default ammo token checks and original instruction-range hashes.

This tool produces private data for the stock dumb-fire launchers. Enabling launcher play requires a gameplay consumer and a qualified match collision scene. Guided variants, other projectile equipment and objective damage are outside this catalog.
